# AGENTS.md

## Mandatory workflow (owner requirement)

1. **Read `PROJECT_LOG.md` before executing any task.** It contains the full history of changes, builds, modules, and discussions. Do not start work until you have read it and know the current project state.
2. After every change, build, module addition, or meaningful discussion, **update `PROJECT_LOG.md`** (Changelog/Build Log section, Discussion Notes, and Modules table as needed).
3. Commit and push to GitHub after each completed module change, with a concise, descriptive commit message.
