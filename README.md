# vihangackumanayaka

Bun + React project.

To install dependencies:

```bash
bun install
```

To start a development server:

```bash
bun dev
```

To build for production:

```bash
bun run build
```

To run for production:

```bash
bun start
```

This project was created using `bun init` in Bun v1.4.0.
